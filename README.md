## Project Overview
This repository contains the solutions for Lab #4a, focusing on modern client-side JavaScript fundamentals including DOM manipulation, event handling (`addEventListener`), input validation, conditional statements, and loops.

## Folder Structure
- `Q1/` — Interactive Text Changer (`index.html`, `script.js`)
- `Q2/` — Smart Number Validator (`index.html`, `script.js`)
- `Q3/` — Dynamic Number Generator (`index.html`, `script.js`)

## How to Run
1. Clone or download this repository to your local machine.
2. Open the folder for the desired question (`Q1`, `Q2`, or `Q3`).
3. Double-click `index.html` to open it in any modern web browser (e.g., Chrome, Edge, Firefox), or run it via VS Code Live Server.
